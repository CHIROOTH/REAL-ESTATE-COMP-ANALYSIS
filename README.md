# Real Estate Comp Analysis

A Python pipeline for Canadian real estate **comparable property analysis** and **price valuation**. Given a property listing, the system finds the K most similar properties using a hybrid location + feature similarity score, then predicts market value using a suite of regression models from a global XGBoost model to KNN-local regressors trained on each property's nearest comps.

---

## Features

- **Hybrid similarity retrieval** — combines Haversine geographic distance with scaled Euclidean feature distance (configurable weighting, default 40% location / 60% features)
- **Four regression models** — Linear Regression, Ridge Regression, Random Forest, and XGBoost, each trained locally on a property's K nearest comps
- **Global XGBoost benchmark** — trained across the full dataset with early stopping for comparison
- **Automated data cleaning** — deduplication and missing-value removal via `preprocessing.py`
- **JSON output** — similarity results and valuation predictions saved for downstream use
- **Diagnostic figures** — scatter plots, feature importance charts, and model comparison bar charts saved to `figures/`

## Getting Started

### Prerequisites

- Python 3.8+
- pip

### Installation

```bash
git clone https://github.com/CHIROOTH/REAL-ESTATE-COMP-ANALYSIS.git
cd REAL-ESTATE-COMP-ANALYSIS
pip install pandas numpy scikit-learn xgboost matplotlib
```

### Data

Place your raw data file at `data/canada_housing_data.csv`. The file should include columns such as `City`, `Province`, `Latitude`, `Longitude`, `Price`, `Bedrooms`, `Bathrooms`, `Acreage`, `Square Footage`, `Property Type`, `Garage`, `Parking`, `Fireplace`, `Waterfront`, `Sewer`, `Pool`, `Garden`, and `Balcony`.

### Running the Pipeline

Run the full pipeline end-to-end:

```bash
python make.py
```

This executes the three stages in order:

1. **`preprocessing.py`** — cleans the raw CSV and writes `data/cleaned_canada_housing_data.csv`
2. **`retrieval.py`** — finds the top-K similar properties for every listing and writes `data/similarity_results.json`
3. **`regressor.py`** — trains and evaluates all regression models, writes `data/valuation_results.json`, and saves plots to `figures/`

You can also run each script individually if you want to re-run a single stage.

### Configuration

Key constants are defined at the top of each script:

| File | Constant | Default | Description |
|---|---|---|---|
| `retrieval.py` | `K` | `5` | Number of comparable properties to retrieve |
| `retrieval.py` | `W_LOC` | `0.4` | Weight given to geographic proximity |
| `retrieval.py` | `W_FEAT` | `0.6` | Weight given to feature similarity |

## How It Works

### 1. Preprocessing
Removes duplicate rows and any rows with missing values, producing a clean CSV ready for analysis.

### 2. Similarity Retrieval
For each property, `PropertySimilarityRetriever` computes:
- **Location distance** — Haversine great-circle distance (km) between properties
- **Feature distance** — Euclidean distance over StandardScaler-normalized features (bedrooms, bathrooms, acreage, sq ft, and one-hot encoded property type/sewer/amenity flags)

Both distances are min-max normalized to [0, 1] and combined as a weighted sum. The K nearest properties are saved per listing.

### 3. Valuation
- **Global XGBoost** — trained on flattened features of every (query, K-neighbors) tuple, validated with early stopping
- **Local models** — for each query property, each model is fit directly on its K comps and used to predict the query price

Output metrics include MAE, RMSE, R², and MAPE across validation and test splits.

## Output

After a successful run you'll find:

- `data/similarity_results.json` — every property paired with its K most similar listings, including distance scores
- `data/valuation_results.json` — per-query predictions from all models plus global model feature importances
- `figures/global_model_results.png` — feature importance + validation scatter for the global XGBoost
- `figures/local_model_scatter.png` — actual vs predicted scatter for each local model across both splits
- `figures/all_models_comparison.png` — RMSE and MAPE bar chart comparing all models on the test set
